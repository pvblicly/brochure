# Pvblicly Weddings — brochure

Brochure site for Pvblicly wedding website themes.

- Edit the `BRAND`, `THEMES`, `PACKAGES` and `FAQS` blocks near the bottom of `index.html` to change links, prices and wording.
- `vieux-papier-intro.mp4` plays in the hero phone.
- `shots/` holds real phone screenshots of each theme. They scroll inside the phone previews. Add or replace images there and list them in `BRAND.shots`.
